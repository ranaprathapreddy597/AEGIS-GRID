# ADR 0001: Deliver Phase 1 and stop at its gate

Status: accepted, 2026-10-14 (Asia/Calcutta).

The repository initially contained only the master constitution. The phase guide
was added during discovery, before source implementation. The supplied Phase 1
requires a genuine simulator-to-React path and supporting infrastructure.

Implement that vertical slice with a transparent bootstrap thermal model. Preserve
the requested monorepo layout and mark every later subsystem as not implemented.
Do not build placeholder command controls, provider stubs presented as production,
or advance into Phase 2 without its work order. The missing-guide assumption made
during discovery was superseded by the supplied actual guide.
