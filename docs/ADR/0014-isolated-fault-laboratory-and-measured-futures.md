# ADR 0014: private fault laboratory and measured futures

The command center keeps live C++ SSE telemetry first, followed by anchored
analysis, investigation/manuals, robust recovery, Ask First and connector receipts.
A responsive hydraulic schematic and six cells are the performant 2D twin; no
unsupported 3D/NPU/cloud claim. Keyboard navigation, reduced motion, loading/error
states and mobile layouts use the same real API flow.

The fault selector intentionally operates on new private C++ instances, never
on the running edge or authorization resource. A strict authenticated request
selects one of 100 packaged scenarios and a uint32 seed. One bounded worker runs
two 600-second trajectories: observe-only and the existing independent shield.
Sixty actual paired samples, measured detection, complete-state fingerprints and
binary hash form a downloadable artifact. Playback at 100x is explicitly recorded
analysis, not live telemetry. Reset only moves the playback cursor; it cannot
reset a latch or operational database. Unknown controls/paths are rejected. This
satisfies UI fault exploration without opening an unapproved mutation route.

The 10K histogram is backed by 5,000 actual paired priors, each baseline/stop at
600 native steps with twenty physics substeps per second: 120 million substeps.
The fixed source is scenario-090 seed 42 at first actual detection. Priors use
Random(110042), target uniform 0..5, severity .3..1, temperature offset -2..2 C
and mask 156. Every row includes source fingerprint, parameters and real metrics.
Data is compressed reproducibly, hash-bound to the summary and native binary,
and checked before API exposure. An independent test reconstructs/re-executes a
stored prior and compares native results exactly. No request claims that these
fixed futures describe the current selected fault or live incident.

Actual network-none 2-CPU/512-MiB run: 40.1391 seconds, 89.09 MiB peak process RSS
(excludes Docker/WSL and other processes). Baseline failures 1971/5000, emergency
stop failures 0/5000. Finite synthetic coverage is not an industrial guarantee.
The UI reports actual production/downtime/energy tradeoffs; no dollar savings,
posterior certainty or GPU acceleration is invented. All external live gates stay
BLOCKED. Physical passkey acceptance remains unverified.

The first browser test incorrectly expected a thermal violation by 300 seconds;
the real result was 63.59 C. Its failing output is retained, and the preview now
uses an explicit 600-second horizon. Test thresholds were not weakened.

The final review found that a fresh install had no live incident to investigate.
An authenticated analysis-investigate endpoint now reconstructs a real detected
private-copy incident, explicitly tagged isolated_analysis, with only delivered
sensor history and the pre-policy native snapshot. It runs the same persisted
LangGraph, Red/Blue optimizer and manual contradiction gate under existing scoped
graph credentials. It never inserts a fake live edge event. An actual browser
selects the fault, investigates it and inspects all real tournament candidates;
healthy/no-detection scenarios refuse rather than inventing an incident. The
separate Ask First sandbox remains explicitly distinct from this blocked incident.
